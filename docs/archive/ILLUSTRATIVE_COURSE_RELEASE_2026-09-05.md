# Illustrative Course and Facilitator Tutorial — Release 10

This release adds a complete, unsaved illustrative course to the Facilitator Course Studio so staff can see what an approval-ready UCC microcredential looks like before creating their own.

## In the Course Studio

- **Load complete example** populates all six design stages without writing to the database.
- The worked course includes 4 objectives, 4 measurable outcomes, 8 skills, 4 sections, 7 learning blocks, 3 programme activities, 8 assessment modes and 13 question formats.
- Stage indicators show completed and outstanding requirements using the same checks applied before academic review.
- Learner preview supports readable HTML, safe document downloads, external resources, direct Colab links and uploaded `.ipynb` notebooks.
- The example certificate gate requires verified identity, a 70% assessment pass and completion of every required activity before a QR-verifiable UCC certificate is generated.
