# Render / Next.js 16 build fixes — 2026-09-03

This revision addresses the concrete errors shown by the Render Docker build.

## Build command

- Production uses `next build --webpack` for Next.js 16 compatibility.
- Docker build stage sets `CI=1`.

## TypeScript sign-in fix

The repository contained three role-specific sign-in pages that pass role information to the shared `AuthForm`, while the shared component previously accepted only `returnTo`.

`AuthForm` now accepts:

- `returnTo`
- optional `portal` (`admin`, `facilitator`, or `learner`)
- optional `inviteToken`

This resolves the reported error in `src/app/admin-signin/page.tsx` and also prevents the same error in the facilitator and student sign-in routes.

## Render storage cleanup fix

`src/app/api/admin/accounts/reset/route.ts` imports `deleteStoredFile` and `deleteIdentityFilesOwnedBy`. They are now implemented and exported from `src/lib/render-storage.ts`.

The implementation:

- deletes both the stored file and its JSON metadata sidecar;
- treats already-missing files as successfully absent, making cleanup idempotent;
- recursively finds identity-verification metadata;
- removes identity files only when their stored `ownerEmail` matches an account being deleted;
- restricts bulk identity cleanup to the `identity-verification` subtree so institutional course materials are not removed accidentally.
